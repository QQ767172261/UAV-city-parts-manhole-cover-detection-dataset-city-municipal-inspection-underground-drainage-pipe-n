### 数据集摘要![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/9cd58a0e2da94a7ba110ced0178cfcc1.png)

本数据集由DJI M4E无人机采集，为低空航拍城市井盖目标检测数据集，包含矩形井盖、圆形井盖、排水井盖三类城市地下管网部件，覆盖不同拍摄高度与角度场景，标注包含XML、TXT格式，可直接用于YOLO系列目标检测模型训练。![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/463422a0f95f42ee9cd287667b7b3a9a.png)

### 应用场景
城市市政巡检、地下排水管网普查、井盖缺失/移位智能识别、智慧城市低空巡查、算法实验、毕业设计![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/66a183f213e846e4b76362fb368bdbef.png)
